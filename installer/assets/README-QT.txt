Vellora (Qt Preview) 0.2.0
==============================

Windows 原生 Markdown 阅读与编辑工具。不依赖 WebView、Electron 或任何浏览器运行时。

启动
----
  * 双击快捷方式打开空窗口，再按 Ctrl+O 选择 .md / .markdown 文件
  * 或把文件拖到窗口里
  * 或右键文件 → 打开方式 → 选择 Vellora Native
  * 命令行：vellora-native.exe <文件路径> [--source-mode]

两种视图（F6 切换）
-------------------
  文档视图：格式化阅读（标题、强调、代码、引用、列表、表格行、图片占位）
  源码视图：直接编辑 Markdown 原文，支持输入法与撤销/重做

当前版本的限制（重要）
----------------------
  * 编辑在源码视图完成；文档视图为阅读视图
  * 表格为真实网格，图片按文档目录安全解析后显示
  * 代码块圆角、引用左侧竖线与部分过渡动效尚未与旧版完全一致
  * 未接管 .md 文件关联，旧版 Vellora 仍是默认程序

快捷键
------
  Ctrl+O  打开          Ctrl+S  保存
  Ctrl+F  查找          Ctrl+H  替换
  Ctrl+Z  撤销          Ctrl+Y  重做
  Ctrl+单击链接        打开链接（相对 Markdown 或 HTTP(S)，需确认）
  F6      切换源码/文档视图

数据与隐私
----------
  本地文件读写，无网络上传，无遥测。
  保存使用原子替换；文件被其他程序修改时会提示覆盖或重新加载。
